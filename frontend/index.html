Como estes números são calculados?

FPS é uma simulação didática a partir de índices de CPU e GPU; não é um teste real. O consumo soma os valores cadastrados e uma estimativa de acessórios, sem medir a tomada ou todos os picos.

Os índices e referências vieram do catálogo original. Veja o README para os limites e fontes declaradas. A seção de verificações usa as fichas oficiais disponíveis e mantém pendente o que não foi confirmado. FPS e consumo continuam estimativas didáticas.
